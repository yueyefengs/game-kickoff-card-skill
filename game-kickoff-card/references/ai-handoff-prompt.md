# 把立项卡交给 AI 的启动提示词

立项卡填好后，有两种用法。

## 用法 A：让 AI 帮你"挑刺"（推荐先做这一步）

> 机明的建议：你不需要把所有问题都想明白再去找 AI。先把想法和这张卡交给他，让他帮你找出还没说清的地方，一起讨论，再由你决定留下哪些、暂时不做哪些。

复制这段提示词，连同你填好的立项卡一起发给 AI：

```
这是我的游戏立项卡。我是作者，最终创意决定由我来拍板。

请你扮演一位资深游戏策划，帮我做三件事：
1. 指出卡里哪些地方还模糊、互相矛盾、或第一版范围过大。
2. 对每个问题给我 2-3 个具体选项，不要替我决定。
3. 告诉我以当前的资源和时间限制，第一版的最小闭环是否现实。

不要急着帮我设计系统或写代码，我们先把方向讨论清楚。

【这里粘贴你填好的立项卡】
```

## 用法 B：方向定了，让 AI 开始做第一版

当立项卡和讨论都收敛后，用这段提示词启动开发：

```
这是我的游戏立项卡，方向已经确定。请严格按照它来做第一版。

要求：
- 只实现"第五项"里定义的最小闭环，不要加卡里放到后面的内容。
- 重点打磨"第二项"里我标注的"最想做好的那段体验"。
- 美术/战斗/装备分别参考"第三项"里列的对象。
- 在"第四项"的资源和平台约束下做实现。

先给我一个第一版的实现方案和任务拆解，我确认后再开始写代码。

【这里粘贴你填好的立项卡】
```

## 进阶：按系统拆分，用文档管理代码

第一版闭环跑通后，把每个系统单独写一份"系统策划案"，然后对 AI 说：

```
这是【战斗系统】的系统策划案。请严格按它实现这个模块的代码。
如果实现和文档不一致，以文档为准。我会通过修改这份文档来调整系统，
而不是直接改代码——请始终让代码与这份策划案保持一致。

【这里粘贴系统策划案】
```
