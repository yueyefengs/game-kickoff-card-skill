## 立项卡之后：用系统策划案管理代码

立项卡定了大方向后，把游戏往下拆成一个个系统，每个系统一份"系统策划案"：

- 战斗系统策划案
- 装备系统策划案
- 成长 / 养成系统策划案
- （按你的游戏补充）

规则：
1. 每份系统策划案描述清楚这个模块的规则。
2. AI 必须**根据系统策划案**把功能实现出来。
3. 有不对的地方，你**只改文档、不直接改代码**——通过文档来管理整个游戏的代码。
4. 立项卡就是这套文档体系的第 0 份：先有方向，再有系统。
